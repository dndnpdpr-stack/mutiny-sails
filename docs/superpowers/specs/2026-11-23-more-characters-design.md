# 캐릭터 추가 설계

## 의도
캐릭터를 10명 → 18명으로 늘려 판마다 조합을 다양하게. 원작 캐릭터 능력과 겹치지 않는 새 능력. 사용자가 8명 목록을 보고 "3명 중 1명 뽑기"로 바꾸자고 함(목록 승인으로 봄).

## 규칙 결정 (내가 정한 것)
- 캐릭터 뽑기 후보 2 → 3명. 고르지 않은 후보는 다시 풀로 돌아가므로 7명이어도 부족하지 않음.
- 도로시 능력은 럼주 규칙을 따름: 두 명만 남으면 불가, 보급 부족 이벤트 중 불가, 대상 체력이 가득하면 불가.
- 오르: 덱이 비면 버린 카드를 섞어 채운 뒤 봄. 다른 사람에게는 카드가 보이지 않음.
- 타라: 받은 카드는 손패 한도 계산 전에 받음.
- 루카: 행운의 동전으로 결과가 바뀌어도 실제 뒤집은 카드의 문양 기준.
- 고든 판정 이유는 해당 카드 종류. 무효가 되어도 카드는 버려짐.
- 펠릭스: 엄폐용 나무통 판정보다 먼저 적용(판정 없이 피함).
- `Action.useAbility`에 `target?`, `targetCardId?` 추가(데릭은 그대로).

## UI
- 캐릭터 뽑기 화면 3장(폰 폭에서 줄바꿈).
- 능력 버튼: 데릭(기존), 도로시(대상 고르기 창), 키키(버릴 손패 + 장비 고르기 창).
- 오르 입력 창: 덱 맨 위 카드 + "그대로 두기 / 맨 밑으로".
- 초상화 8장을 기존 캐리커처 스타일 SVG로(교체 가능한 구조 유지), 이모지 대체 등록.

## AI
- 도로시: 같은 편으로 보이는(점수 < 0) 다친 사람 회복. 키키: 가치 낮은 손패로 적의 장비 제거. 오르: 가치 높은 카드면 두고 아니면 밑으로.
