# 폰트 교체 + 캐릭터 초상화 — 짧은 설계

- 작성일: 2026-11-20 · 상태: 승인됨 (2026-11-20)
- 기반: `2026-11-19-table-ui-and-character-draft-design.md`

## 의도
사용자가 플레이해 보고 (1) 한글 명조체(Georgia/바탕 계열)가 예쁘지 않다, (2) 캐릭터가 이모지뿐이라 카드에 캐릭터 그림이 보였으면 좋겠다고 요청했다. 그림체는 샘플을 보고 "아직 마음에 들진 않지만 A(코믹 셀 채색)로 진행하고 나중에 다시 바꾸자"고 했다. **그래서 그림은 나중에 쉽게 갈아끼울 수 있는 구조가 핵심이다.**

## 목표 / 비목표 / 실패 조건
- 목표: 화면 전체 폰트를 프리텐다드로 통일. 캐릭터 10명에게 각자 초상화를 그려 캐릭터 뽑기 카드(큰 초상화), 상대 패널·내 정보 칸(동그란 얼굴), 결과 화면에 보여준다.
- 비목표: 카드(칼질 등) 그림 교체, 테이블 배치 변경, 효과음.
- 실패 조건: 그림을 바꾸려면 화면 코드를 고쳐야 하는 구조. 외부 폰트 서버 의존. 원작 카드 게임의 캐릭터 그림을 닮게 그리는 것.

## 검토한 방식
- 폰트: **npm 패키지 `pretendard`를 번들에 포함 (선택)** / CDN 링크(접속 환경에 따라 늦게 뜨거나 깨짐) — 외부 의존이 없어서 전자.
- 그림: **캐릭터마다 SVG 파일 하나 + 등록표 (선택)** / 컴포넌트 코드 안에 SVG 직접 작성(바꾸기 어려움).

## 정한 것
- 폰트: `pretendard` npm 패키지(가변 폰트 CSS)를 `main.tsx`에서 import. `--serif` 등 기존 폰트 변수를 프리텐다드로 바꾸고, 제목·카드 이름·캐릭터 이름은 굵기(700~800)로 구분.
- 그림 파일: `src/ui/art/portraits/{characterId}.svg` (10개). 등록표 `src/ui/art/portraits.ts`가 `PORTRAITS: Partial<Record<CharacterId, string>>`(Vite가 주는 URL)를 내보낸다. 나중에 교체는 파일만 바꾸거나, PNG 등으로 바꾸면 등록표의 import 한 줄만 바꾼다.
- 그림이 없는 캐릭터는 지금의 `CHARACTER_FACE` 이모지로 대체 표시.
- 컴포넌트 `Portrait({ id, variant: 'card' | 'face' })`: `card`는 세로형 상반신(166×200 비율), `face`는 같은 그림을 원형으로 얼굴 부분만 잘라 보여준다(CSS `object-position`으로 얼굴 쪽 정렬). 그래서 그림 파일은 캐릭터당 하나.
- 그림체 A(코믹 셀 채색): 굵은 잉크 외곽선(#1b120a), 과장된 이목구비, 차분한 색 면 + 그림자 한 단계, 단색 배경, viewBox 0 0 166 200, 얼굴은 위쪽 절반(대략 y 10~135)에 오게. 캐릭터마다 특징 하나씩:
  - 톰: 요리사 모자, 팔자 콧수염, 국자 · 마고: 어깨의 앵무새, 머리 두건 · 루: 덥수룩한 수염, 밀수 자루 · 데릭: 포수 모자, 화약 그을음, 도화선 · 오르소: 큰 덩치, 닻 문신, 대머리 · 니코: 날카로운 눈, 챙 모자, 손가락 사이 동전 · 한나: 땋은 머리, 닻 목걸이 · 실라: 삼각모, 망원경, 흉터 · 비비: 고글, 화약통 · 브루노: 각진 턱, 붕대, 굵은 팔짱
- 원작 캐릭터 그림을 참고하거나 닮게 그리지 않는다.

## 구현자에게 맡기는 것
SVG 세부 모양·색, CSS 크기 조정, 이모지 대체 표시 방식.
