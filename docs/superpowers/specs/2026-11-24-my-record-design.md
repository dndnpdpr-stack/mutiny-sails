# 내 전적 — 설계

**왜:** 사용자 요청("전적보기는 필요할듯"). 승률 밸런스는 지금이 적당하다고 해서 손대지 않음.

- 끝까지 끝난 판만 이 브라우저(localStorage `mutiny.record`)에 쌓는다. 관전 중 새로 하기로 나간 판은 세지 않는다.
- 승패: 내 편이 이겼으면 승리, 현상금 사냥꾼은 현상금을 받았을 때만 승리.
- 역할별(선장·충성 선원·항해사·반란 선원·이중 첩자·첩자·현상금 사냥꾼) 판·승·승률, 통산, 지금 연승·최고 연승.
- 결과 화면: "내가 이겼어요/졌어요"와 통산·연승·이번 역할 전적 한 줄. 시작 화면: "📜 내 전적" 버튼 → 역할별 표, 초기화(두 번 눌러 확인).
