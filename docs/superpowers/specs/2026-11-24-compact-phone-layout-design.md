# 폰 세로 압축 배치 — 설계 (작은 변경)

**왜:** 폴드 바깥 화면(약 344~372px 폭) 세로로 하면 화면이 두 장 높이(360×720에서 내용 1,114px)라 상대와 손패를 한눈에 못 본다. 넓은 폰(412px)은 상대 4명이 한 줄이라 거의 맞았다.

**결정 (CSS만, `max-width: 640px`):**
- 상대: 활 모양 들쭉날쭉을 끄고 `minmax(76px,1fr)` 격자 칩으로. 얼굴 34px, 손패 수·거리를 한 줄에, 장비는 그림만 작은 칸으로. 선장 리본도 작게.
- 가운데: 카드 더미 `zoom: 0.56`, 항해 일지는 최근 몇 줄(62px)만, 제목 숨김.
- 내 자리: 얼굴 40px, 글씨 줄임, 패널은 폭을 꽉 채움, 역할 카드 68px.
- 손패: 위 여백을 들어 올릴 만큼만(30px), 칸 폭을 꽉 채워 카드가 잘리지 않게(원래 좁게 줄어 잘리던 버그), `zoom: 0.85`.

**확인:** 헤드리스 크롬 360×720 — 5인 720px(딱 맞음), 7인 752px(약간 스크롤). 412×860 5인 맞음. 데스크톱·펼친 폴드(640px 초과)는 그대로.
