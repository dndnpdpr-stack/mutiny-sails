# 역할 카드 뽑기 — 짧은 설계

- 작성일: 2026-11-20 · 상태: 승인됨 (대화에서 1번 방식 선택)

## 의도
지금은 역할이 자동 배분되고 내 카드가 뒤집히는 연출만 있다. 시작부터 "직접 고르는" 긴장감을 주기 위해, 펼쳐진 뒤집힌 역할 카드 중 한 장씩 골라 뽑는다. 나중에 멀티플레이에서는 친구들이 각자 고른다.

## 정한 것
- 게임 생성 시 역할 카드(인원별 구성)를 섞어 슬롯 0..n-1에 엎어 둔다. 자리에는 아직 역할이 없다.
- 정해진 첫 자리부터 시계 방향으로 한 명씩(1인 플레이는 사람이 먼저, 멀티플레이는 방장이 먼저 — 2026-11-20 사용자 요청으로 변경), 남은 슬롯 중 하나를 고른다(`drawRole`). 고른 역할은 본인만 본다. **선장 카드는 뽑는 즉시 모두에게 공개.**
- 전원이 뽑으면 지금처럼 선장부터 캐릭터 뽑기 → 체력·손패 → 선장 첫 턴.
- `GameConfig.roles`를 주면(테스트용) 뽑기 없이 바로 배정(기존 동작).
- 입력 대기 `{ kind: 'drawRole', seat, slots: number[] }`(남은 슬롯 번호, 내용은 비공개), 행동 `{ type: 'drawRole', slot }`. 시간 초과 기본값: 첫 슬롯. AI: 무작위 슬롯.
- 이벤트 `roleDrawn { seat, slot, role }`: 본인에게는 역할, 다른 사람에게는 `role: null`(선장이면 모두에게 'captain').
- 화면 상태: 아직 안 뽑은 자리 `role: null`, 나도 안 뽑았으면 `myRole: null`.
- 화면: 뽑기 화면 위쪽에 남은 역할 카드 뒷면을 펼쳐 놓고, 내 차례면 눌러서 뽑기("역할 카드를 뽑으세요"), 아니면 "○○이 역할 카드를 고르는 중…". 뽑으면 내 카드가 뒤집혀 공개. 선장이 나오면 "👑 선장은 ○○" 표시. 그다음 기존 캐릭터 뽑기.

## 비목표
