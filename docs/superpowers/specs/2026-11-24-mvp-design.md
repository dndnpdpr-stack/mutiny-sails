# 결과 화면 MVP — 설계 (작은 변경)

**왜:** 게임이 끝났을 때 누가 제일 활약했는지 보고 싶다(사용자 요청).

**결정:**
- 엔진이 게임 내내 자리별 **준 피해**(자기 자신 제외)와 **쓰러뜨린 수**를 센다(`Game.stats`). 화면용 이벤트는 최근 100개뿐이라 따로 센다. 게임이 끝난 뒤에만 view에 실린다(`PlayerView.stats`).
- MVP = **이긴 편** 중 `피해 + 처치×3 + 살아남음 1`이 가장 큰 사람(같으면 앞자리). 첩자 승리면 첩자.
- 결과 화면 맨 위에 금색 MVP 칸(이름·캐릭터·피해·처치), 해당 자리에 🏅 MVP 띠, 모든 자리에 "피해 n · 처치 n".
