# 손패 카드 설명 보기 설계

## 의도
새 확장 카드가 익숙하지 않아서, 내 턴에 손패를 고를 때 카드 효과를 바로 확인하고 싶다. 지금은 설명이 시작 화면 "게임 방법"에만 있고, 게임 중에는 마우스 올리기(title)로만 보여 폰에서는 볼 수 없다.

## 목표 / 비목표
- 목표: 내 턴에 손패 카드를 누르면 설명이 보이고, 실수로 카드가 나가지 않는다. 폰에서도 된다.
- 비목표: 다른 사람이 낸 카드, 상대 장비, 바다 이벤트, 항해일지의 설명 (사용자가 내 손패만 필요하다고 함).
- 안티 목표: 카드 내기가 지금보다 헷갈려지는 것.

## 접근 (사용자가 A를 고름)
- **A. 처음 누르면 설명, 한 번 더 누르면 내기** ← 선택. 폰에서 바로 알 수 있고 실수로 카드를 내지 않음. 대신 대상 없는 카드는 한 번 더 눌러야 함.
- B. 길게 누르기/오른쪽 클릭: 흐름은 안 바뀌지만 기능을 알기 어렵고, 폰 제스처와 엉킴.
- C. "?" 설명 모드 버튼: 볼 때마다 모드를 켰다 꺼야 함.

## 동작
- 내 턴에 손패 카드를 처음 누르면: 그 카드가 위로 올라오고 손패 위에 설명창(이모지, 이름, 확장이면 "확장" 표시, 설명 문구)이 뜬다.
  - 대상이 없는 카드: 설명창의 [내기] 버튼 또는 같은 카드를 다시 누르면 낸다.
  - 대상이 있는 카드: 지금처럼 바로 대상 고르기 상태가 되고, 설명창은 같이 떠 있다. 같은 카드를 다시 누르면 취소(지금과 같음).
  - 지금 낼 수 없는(흐린) 카드: 설명만 보이고 [내기] 버튼은 없다.
- 다른 카드를 누르면 설명창이 그 카드로 바뀐다. Esc, 턴 종료, 카드를 낸 뒤에는 닫힌다.
- 남의 공격에 응답하는 상황(칼질 막기 등)은 지금처럼 누르면 바로 응답한다. 시간 제한이 있는 응답이라 한 번 더 누르게 하지 않는다. (내 판단)
- 내 턴이 아닐 때 응답에 쓸 수 없는 카드를 누르면 설명만 보여 준다. 해가 없고 같은 창을 재사용하므로 함께 넣는다. (내 판단)

## 빌더에게 맡기는 것
- 설명창 위치·스타일은 기존 PromptNote/AbilityNote 쪽지 스타일을 따르고, 폰 폭에서 손패를 가리지 않게.
- 설명 문구는 `CARD_CATALOG`의 `text`를 그대로 쓴다.
