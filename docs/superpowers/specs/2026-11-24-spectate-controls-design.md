# 관전 중 빨리 감기·새로 하기 — 설계 (작은 변경)

**왜:** 내가 쓰러진 뒤 AI끼리 끝날 때까지 지켜보는 게 지루하다.

**결정:** 내가 죽으면 손패 자리의 "관전 중" 띠에 버튼 두 개를 둔다. 살아 있을 땐 보이지 않는다.
- **⏩ 빨리 감기** (켜기/끄기, `aria-pressed`): AI 행동 간격 700ms → 100ms(`FAST_AI_MS`), 연출 끔. 끝나면 평소대로 결과 화면.
- **새로 하기**: 결과를 건너뛰고 설정 화면으로(결과 화면 "다시 하기"와 같은 동작). 이미 진 상태라 확인 창 없음.
- 새 게임이 시작되면 빨리 감기는 꺼진 상태로 돌아간다.

**검토한 다른 방법:** "결과 바로 보기"(과정을 전혀 못 봄 — 빨리 감기로도 몇 초면 끝남), 같은 설정으로 즉시 재시작(설정을 바꾸고 싶을 때가 있음).

**구현 메모:** `AiPlayer.setDelay(ms)`, `useLocalGame`이 `fast`/`setFast` 제공, App은 `fast`일 때 `useAnimatedView`의 `enabled`를 끈다.
