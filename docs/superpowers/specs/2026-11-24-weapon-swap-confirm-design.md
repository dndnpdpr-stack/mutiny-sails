# 무기 교체 확인 — 설계 (작은 변경)

**왜:** 무기는 하나만 낄 수 있어서 새 무기를 내면 있던 무기가 말없이 버려진다. 실수로 좋은 무기를 잃는다(사용자 요청).

**결정:** 무기를 이미 낀 채로 무기 카드를 내면(손패 탭이든 카드 설명의 [내기]든) 바로 내지 않고 "무기 바꾸기" 쪽지를 띄운다.
"지금 낀 권총을(를) 버리고 머스킷을(를) 낄까요?" + 두 카드 그림, [바꾸기] / [그대로 두기]. Esc·턴이 넘어가면 닫힌다.
무기가 없으면 예전처럼 바로 낀다. 무기 여부는 카드 목록의 `weapon` 표시(권총·머스킷·장총·갑판 대포·쌍권총·작살). 엔진 규칙은 그대로.
