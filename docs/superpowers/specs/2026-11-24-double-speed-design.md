# 2배속 모드 + 7인 폰 화면 맞추기 — 설계 (작은 변경)

**2배속:** 손패 아래 버튼 줄(턴 종료 왼쪽)에 [2×] 토글(`aria-pressed`).
- 켜면 AI 행동 간격 절반(700→350ms), 연출은 항상 2배속(`useAnimatedView`의 `minSpeed: 2`).
- 선택은 이 브라우저에 기억(`localStorage` `mutiny.doubleSpeed`, 막혀 있으면 이번 접속 동안만).
- 관전 중 ⏩ 빨리 감기(100ms, 연출 끔)가 켜져 있으면 그쪽이 우선.
- 처음엔 오른쪽 위에 두려 했으나 폰에서 상대 칩을 가려 버튼 줄로 옮김.

**7인 폰 화면:** 상대가 5명 이상(`.opp-arc:has(> .opp:nth-child(5))`)이면 칩 얼굴 28px·글씨를 한 단계 더 줄이고 일지 48px. 360×720에서 6·7인 모두 720px.
