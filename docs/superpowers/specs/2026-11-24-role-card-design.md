# 게임판에 내 역할 카드 두기 — 설계 (작은 변경)

**왜:** 게임 도중 내 역할(과 목표)을 잊어버린다. 이름 옆 글자("· 반란 선원")는 눈에 잘 안 띈다.

**결정:** 진짜 카드처럼, 내 캐릭터 패널 바로 오른쪽에 작은 역할 카드(이모지·역할 이름·목표)를 항상 놓는다.
- 역할 뽑기 화면과 같은 `RoleCard` 디자인을 작은 크기(`size="sm"`)로 재사용.
- 역할을 아직 모르면 뒷면. 죽어서 관전 중이어도 계속 보인다.
- 이름 옆 역할 글자는 지운다(카드와 중복).
- 휴대폰에서도 캐릭터 패널과 역할 카드는 한 줄에 나란히(`.me-cards` 묶음), 손패는 그 아래.

**검토한 다른 방법:** 화면 위 띠(카드 느낌이 아님), 눌러야 보이는 뒤집기(혼자 하는 게임이라 가릴 이유 없음) — 사용자가 카드 방식을 골랐다.

**테스트:** `tests/ui/table.test.tsx` — 역할 카드에 이름·목표가 보이고 패널 글자엔 없다 / 관전 중에도 보인다 / 역할을 모르면 뒷면.
