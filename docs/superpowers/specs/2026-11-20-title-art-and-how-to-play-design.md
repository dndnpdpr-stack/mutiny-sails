# 타이틀 그림 + 게임 방법 — 짧은 설계

- 작성일: 2026-11-20 · 상태: 승인됨 (2026-11-20)
- 기반: `2026-11-20-font-and-character-portraits-design.md`

## 의도
사용자 피드백: 시작 화면이 밋밋하다 → 타이틀 그림. 그리고 메인 화면에서 게임 방법(캐릭터, 카드 소개 등)을 볼 수 있으면 좋겠다. 처음 하는 친구도 시작 화면에서 규칙을 익힐 수 있게 하는 게 목적.

## 정한 것
### 타이틀 그림
- `src/ui/art/title.svg` 한 파일(초상화처럼 갈아끼우기 쉬움). 코믹 셀 채색 스타일(굵은 외곽선 #1b120a, 색 면 + 그림자 한 단계).
- 장면: 해질녘 바다, 찢어진(칼자국 난) 돛의 해적선, 펄럭이는 해골 깃발. 가로형(대략 viewBox 0 0 480 220).
- 움직임: 배가 천천히 흔들리고 깃발이 펄럭임(SVG 내부 CSS 애니메이션). `prefers-reduced-motion: reduce`면 정지.
- 그림 아래(또는 위에 겹쳐) "반란의 돛" 로고 글자: 금색, 어두운 테두리, 굵게. 부제 "정체를 숨긴 해적들의 카드 게임".
### 게임 방법
- 시작 화면 "출항" 옆에 "게임 방법" 버튼 → 양피지 책 모양 창(`role="dialog"`, 이름 "게임 방법"), 탭 4개: 기본 규칙 / 역할 / 캐릭터 / 카드.
  - 기본 규칙: 목표, 턴 진행(2장 뽑기 → 카드 내기 → 손패 정리), 거리·사거리, 칼질 턴당 1번, 체력 0 → 럼주로 버티기, 쓰러짐 보상(반란 선원을 쓰러뜨리면 3장)·벌칙(선장이 충성 선원을 쓰러뜨리면 손패·장비 모두 버림).
  - 역할: 선장·충성 선원·반란 선원·첩자 역할 카드 + 승리 조건(`ROLE_GOAL`), 인원별 구성표(4명: 선장·첩자·반란2 / 5명: +충성1 / 6명: +반란1 / 7명: +충성1).
  - 캐릭터: 10명 `CharacterCard`(초상화, 이름, 체력, 능력) — 고르기 버튼 없음.
  - 카드: 즉시 사용 12종, 장비 10종을 `CardFace` 모양 + 이름·장수·효과. 판정 카드(엄폐용 나무통 ♥, 화약통 ♠2~9, 영창 ♥)는 카탈로그 문구에 이미 조건이 있음.
- 캐릭터·카드 내용은 `CHARACTER_INFO`, `CARD_CATALOG`, `ROLE_GOAL`에서 바로 가져온다(설명과 게임이 어긋나지 않게).
- 닫기 버튼과 Esc로 닫힘. 좁은 화면에서는 창 안에서 세로 스크롤.
- 이번에는 시작 화면에서만. 게임 중 "?" 버튼은 나중에 같은 창 재사용(Claude의 결정).

## 비목표
