# 역할 카드 뽑기 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 시작 시 펼쳐진 역할 카드 중 한 장씩 골라 뽑게 한다. **Spec:** `docs/superpowers/specs/2026-11-20-role-draw-design.md`

## Global Constraints
- 엔진은 ui/host/ai를 import하지 않음. 남의 역할은 선장·쓰러진 사람·게임 종료 외 비공개. 화면 문자열 한국어.
- `GameConfig.roles` 강제 시 기존 동작 유지(기존 엔진 테스트 불변).

## Review Focus
1. 사람이 0번 자리가 아니라 AI가 먼저 뽑는 경우 → 진행 상황이 보이고 내 차례에 카드가 나타남 (Task 2 테스트)
2. 이미 뽑힌 슬롯을 고르는 행동 → 거부 (Task 1 테스트)
3. 다른 사람이 뽑은 역할이 내 화면·이벤트에 새지 않음(선장 제외) (Task 1 테스트)
4. 7명에서도 끝까지 뽑기 후 캐릭터 뽑기로 넘어감 (Task 1 테스트)
5. 시뮬레이션 300판이 뽑기 단계 포함으로 통과 (Task 1)
