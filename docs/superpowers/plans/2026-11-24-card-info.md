# 손패 카드 설명 보기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 손패 카드를 처음 누르면 설명창이 뜨고, 대상 없는 카드는 한 번 더 누르거나 [내기]로 낸다.

**Architecture:** `TableScreen`의 기존 `selectedId` 상태를 "설명 중인 카드"로 넓힌다. 대상 고르기는 지금처럼 그 카드의 hint에 `targets`가 있을 때만 켜진다. 설명창은 모달이 아닌 쪽지(`CardInfoNote`)로, 손패 위에 떠서 자리 클릭을 막지 않는다.

**Tech Stack:** React 18, framer-motion, vitest + Testing Library

**Spec:** `docs/superpowers/specs/2026-11-23-card-info-design.md`

## Global Constraints
- 설명 문구는 `CARD_CATALOG[kind].text` 그대로. 확장 카드는 "확장" 표시.
- 응답 상황(`responseWith`가 카드 묶음을 돌려줄 때)은 지금처럼 한 번에 응답.
- 폰 폭(≤640px)에서 손패를 가리지 않는다.

## Review Focus
1. 설명 중이던 카드를 낸 뒤(latest.myHand에서 사라짐) 설명창이 남지 않는다.
2. 내 턴이 끝나면 설명창이 닫힌다 (턴 종료 버튼이 아니라 시간 초과로 넘어가도).
3. 대상 카드를 고른 상태에서 다른 사람 자리를 누를 수 있다 (설명창이 클릭을 막지 않음).
4. 응답할 차례에 피하기를 누르면 설명창 없이 바로 응답된다.
5. 낼 수 없는 카드의 설명창에는 [내기]가 없다.

### Task 1: 설명창과 두 번 누르기 흐름

**Files:**

**Interfaces:**
- Produces: `CardInfoNote(p: { card: CardView; onPlay: (() => void) | null })` — `role="dialog"`, `aria-label="카드 설명"`; `onPlay`가 있으면 [내기] 버튼.

- [ ] **Step 1: 실패하는 테스트** (기존 'plays a no-target card immediately'를 대체)
  - `first click on a no-target card shows its text, second click plays it`: 럼주 클릭 → send 없음, dialog '카드 설명'에 럼주 text 보임 → 다시 클릭 → `{ type: 'playCard', cardId: 'r1' }`.
  - `the play button in the card info plays a no-target card`.
  - `an unplayable card shows its text without a play button`: hint 없는 피하기 클릭 → 설명 보임, '내기' 버튼 없음, send 없음.
  - `a target card shows its text while targets are marked`: 칼질 클릭 → 설명 보임 + panel(2) targetable, panel(2) 클릭 → playCard target 2.
  - `expansion cards are tagged`: 불붙은 배(fireShip) 설명에 '확장'.
  - `responding still plays at once`: respondAttack 중 피하기 클릭 → 바로 respond, 설명창 없음.
  - `the card info closes when my turn passes`: 설명 연 뒤 pending을 남의 턴으로 rerender → 설명창 없음.
  - `the card info closes once the card left my hand`: rerender로 myHand에서 뺌 → 설명창 없음.
